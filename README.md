# EDA-Titanic-
# 🚢 Titanic Dataset - Exploratory Data Analysis (EDA) Project

A simple Exploratory Data Analysis (EDA) project on the Titanic dataset using Python. The project uses visualizations and statistical summaries to understand survival patterns among passengers.

---

## 📌 Project Overview

This project analyzes the Titanic dataset to explore relationships between passenger features such as age, gender, class, and fare with survival outcomes. The analysis is visualized using multiple subplots for better comparison.

---

## 🧰 Tools & Libraries Used

- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib

---

## 📊 Features of the Project

- Data loading using built-in Seaborn dataset
- Handling missing values (Age imputation)
- Data exploration using `.info()` and `.isnull()`
- Multiple visualizations using subplots:
  - Survival count
  - Gender vs Survival
  - Passenger class distribution
  - Age distribution
  - Fare distribution
  - Correlation heatmap

---

## 📈 Visualizations

The project displays all plots in a single window using subplots for better comparison and analysis.

Key plots include:
- Survival distribution
- Gender-based survival comparison
- Passenger class distribution
- Age & fare distributions
- Feature correlation heatmap

---

## 🧠 Key Insights

- Females had a higher survival rate compared to males.
- Passengers in first class had better chances of survival.
- Most passengers were between the age of 20–40 years.
- Fare and passenger class show noticeable correlation with survival.
